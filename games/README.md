# 🎮 Games

Web games and game projects — from quick browser apps to more serious builds.

## Structure

Each game lives in its own folder with its own README:

```
games/
  <game-name>/
    README.md        # what it is, how to run, how to deploy
    ...
```

## Ideas backlog

- [ ] Browser game (HTML5 canvas / JS or a small framework)
- [ ] Multiplayer experiment (websockets)
- [ ] Something more serious (game engine, Steam-able?)

## Deploy targets

Browser games deploy well to GitHub Pages, Vercel, or Netlify — aim for a live link in every game's README.
