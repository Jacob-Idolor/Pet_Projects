## 🎯 Position-Specific Strategy Compass

### UTG (Under the Gun)
```
     TIGHT
       ↑
       │
FOLD ←─●─→ RAISE
       │
       ↓
     NEVER
    (No limping)
```
**Strategy: Ultra-tight, raise or fold**

### MP (Middle Position)
```
   BALANCED
       ↑
       │
FOLD ←─●─→ RAISE
       │
       ↓
   SET MINE
  (Small pairs)
```
**Strategy: Balanced value + speculative**

### HJ-CO-BTN (Late Position)
```
   AGGRESSIVE
       ↑
       │
STEAL←─●─→ RAISE WIDE
       │
       ↓
    POSITION
   (Maximize)
```
**Strategy: Steal blinds, play aggressive**

### SB (Small Blind)
```
    VS BB: WIDE
       ↑
       │
3-BET←─●─→ FOLD
       │
       ↓
  VS OPENS: TIGHT
```
**Strategy: Complex, position-dependent**

### BB (Big Blind)
```
   DEFEND WIDE
       ↑
       │
CALL ←─●─→ 3-BET
       │
       ↓
   POT ODDS
  (Calculate)
```
**Strategy: Defend based on pot odds**

## 🎯 Key Principles (Print & Memorize!)

### The Golden Rules

1. **Position > Cards**
   ```
   KJo from BTN > AJo from UTG
   ```

2. **Later = Wider**
   ```
   UTG: 10% → BTN: 45%
   ```

3. **Information = Money**
   ```
   Acting last = Seeing all actions first
   ```

4. **Steal Relentlessly**
   ```
   Late position + Tight blinds = PROFIT
   ```

5. **Respect Early Position**
   ```
   UTG raise = STRONG range
   ```
