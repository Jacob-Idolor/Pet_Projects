# StocksWatch

The repository for [stockswatch.cc](https://stockswatch.cc), a static Astro dashboard for tracking the AI data-center market. It is deployed through AWS S3 and CloudFront.

## Structure

```text
stocks/
  AGENTS.md           # Codex project instructions
  radar/              # active Astro application, scripts, data, and infrastructure
```

## Application

The active application lives in [`radar/`](radar/):

- `/` is the AI Data Center screener.
- `/watchlist.html` is the archived group watchlist.
- Market snapshots are generated by scripts and CI, stored as static JSON, and served through the CDN.
- The historical local Flask implementation is preserved under `radar/archive/` and is not deployed.

## Local development

```bash
cd radar
npm ci
npm run dev
```

On Windows PowerShell, use `npm.cmd` if the PowerShell execution policy blocks `npm.ps1`:

```powershell
npm.cmd ci
npm.cmd run dev
```

Useful offline checks:

```bash
npm test
npm run typecheck
npm run screener:schema
```

See [`radar/README.md`](radar/README.md) for project commands and [`radar/ARCHITECTURE.md`](radar/ARCHITECTURE.md) for the code and data flow.

## Working with Codex

Codex reads [`AGENTS.md`](AGENTS.md) for repository-specific rules. Ask it to implement a change and run the relevant checks; request commits, pushes, deployments, or live-data operations explicitly when you want them.
