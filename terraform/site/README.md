# Static Terraform learning site

Browser-based Terraform learning — modules, simulated CLI, quizzes.

## Local preview

```bash
cd terraform/site
npm install
npm run dev
```

Open http://localhost:4321

## Features

- `/learn.html` — module index
- `/modules/*.html` — lessons + quiz + terminal per topic
- `/terraform.html` — Terraform simulator + missions
- `/practice-*.html` — troubleshooting scenarios
- Progress tracker at `/progress.html`
